## 上市公司全量公告

接口：anns_d
描述：获取全量公告数据，开始于1999-01-01,每2个小时更新一次，提供pdf下载URL
限量：单次最大2000条数，可以跟进日期循环获取全量
权限：本接口数据需单独开通权限，请参考[权限列表](https://tushare.pro/document/1?doc_id=290)，前往[权限中心](https://tushare.pro/weborder/#/permission)申请（需勾选“公告数据”）。

输入参数

| 名称 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- |
| ts_code | str | N | 股票代码 |
| ann_date | str | N | 公告日期（yyyymmdd格式，下同） |
| start_date | str | N | 公告开始日期 |
| end_date | str | N | 公告结束日期 |

输出参数

| 名称 | 类型 | 默认显示 | 描述 |
| --- | --- | --- | --- |
| ann_date | str | Y | 公告日期 |
| ts_code | str | Y | 股票代码 |
| name | str | Y | 股票名称 |
| title | str | Y | 标题 |
| url | str | Y | URL，原文下载链接 |
| rec_time | datetime | N | 发布时间 |

接口调用

```text
pro = ts.pro_api()

df = pro.anns_d(ann_date='20230621')

```
