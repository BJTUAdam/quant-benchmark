# Tushare常见陷阱

这是本系统相关的常见错误表，不声称穷尽所有Tushare问题。字段含义、积分、更新频率和单次上限应以当前 [离线官方接口](tushare/index.md) 为准；官方文档未说明的事项写为待确认。

## 连接与接口能力

|易错处|正确处理|
|---|---|
|直接 `import tushare` 后 `ts.pro_api()`|本项目用 `from finlab import tushare as ts`，通过任务桥接|
|把桥接token当作Tushare账号token|它只在任务桥接范围内使用，不发给官方服务或其他地址|
|看到246个接口文档就任意调用|先核对当前 `bridge_contract.json` 的接口、字段和标的|
|动态方法可访问就认为有权限|动态属性只构造请求；授权和冻结在服务端检查|
|把 `pro_bar` 当成HTTP API名称|它是SDK组合包装；本平台只实现列出的包装范围|
|把旧版爬虫 `get_hist_data`、`get_realtime_quotes` 当Pro接口|旧版函数不属于本系统的Pro HTTP契约|
|直接照搬官方示例的积分/频次到本地缓存|官方限制适用于账号采集，当前冻结回放另按任务约束|
|请求失败就重试到成功|先看错误类型；未授权、未来查询、未知字段和未冻结不能靠重试解决|

## 时间与可见性

|易错处|正确处理|
|---|---|
|所有日期都用ISO切片|日线、分钟、年月、季度分别按API参数格式生成|
|使用电脑当前日期或官方示例年份，或按虚拟年份套用真实股灾/政策|虚拟年份默认位于未来数百年，只是时间轴标签；只用任务时钟、已可见数据与允许范围|
|把财务 `end_date` 当公告时间|报告期不等于可用时点；核对公告、实际公告及修订记录|
|用现在下载的财务值代表当时已知值|只能使用桥接在当前时点返回的可见版本|
|删除所有含未来日期的元信息|已公告的未来到期日可合法可见，由桥接时点规则判断|
|根据虚拟日期周六周日判断休市|依据任务交易日历及事件，不能重建工作日日历|
|把期货夜盘自然日直接当交易日|使用返回的交易日归属，不按时钟日期猜|
|用名称、合约年月推导真实时期再查数据|名称代码保持原值，查询仍只使用虚拟时间和任务权限|
|在当前收盘事件查询未来开盘或下一段|后续数据由平台逐步开放；策略只能查询当前事件已可见信息|
|把任务总范围当作当前已开放范围|按阶段累计披露，正式策略另受当前事件时钟限制；范围结束点不包含|
|请求跨越边界后期待返回合法部分|部分越界也整次报TIME_RANGE_EXCEEDED，记录request_id并修正范围|
|将越界异常变为空表或补零|错误没有行情返回；不能当作停牌、无成交或交易信号|
|遇到BRIDGE_AUDIT_UNAVAILABLE就切换上游|这是平台审计故障，报告错误让平台处理；无行情返回，不绕过|

未来虚拟日期可能超过 Pandas 默认纳秒日期上限。用标准库 `datetime/date` 解析，或保持等宽日期字符串排序；不要用 `errors="coerce"` 把有效虚拟日期悄悄变成 `NaT`。不通过真实名称、代码或外部事件日历猜测实际年份。

## 字段、单位与缺失

|易错处|正确处理|
|---|---|
|把代码转成整数|保留字符串及交易所后缀，避免前导零丢失|
|所有接口的 `vol` 都当股数|逐接口查看单位；股票日线常见为手，进入平台事件的volume已按契约转换|
|所有 `amount` 都当元|官方接口常有千元、万元等口径，按该字段说明判断|
|把百分数值直接作为比例|如涨跌幅、换手率等，查明是百分数还是小数再换算|
|把金额、百分比、份额统一套同一倍率|不同字段和资产分别规范化，不能见数值就乘100|
|把空DataFrame自动解释为停牌|还可能是范围、字段、覆盖或授权问题；按任务缺失约定处理|
|把NaN、None、空字符串、`--` 全填0|分别识别缺失；没有价格不能当作零价成交|
|财务字段的默认显示等于必填输入|输入表和输出表分开阅读；不把输出列作为查询参数|
|认为 `fields=""` 总会包含全部所需列|显式请求授权字段，检查返回列是否存在|

## 时序与组合处理

|易错处|正确处理|
|---|---|
|对倒序DataFrame直接rolling/shift|先按标的和日期升序排列，避免把未来方向当过去|
|跨标的直接diff或rolling|先groupby标的；横截面排名按同一可见时点对齐|
|一次请求刚好未达到limit就宣布全部覆盖|按桥接 `has_more/next_offset` 或明确的范围/覆盖契约判断|
|重复分页时offset不推进|检查next_offset严格增大；有限页数失败退出|
|用财务多版本表与日线随意merge|明确唯一键、报告口径和时点，检查连接是否扩行|
|连续合约代码当可交易分合约|研究序列与下单合约分开，按任务真实分合约规则交易|
|当前指数成分回填整个历史|使用任务提供的历史成分，避免幸存者偏差|
|基金净值等于交易所ETF成交价|`fund_nav` 与 `fund_daily` 用途不同，不混作成交行情|
|前复权研究价与原始价混合算盈亏|复权仅用于约定的研究计算，撮合和公司行为由平台处理|
|复权因子缺失时默认为1|明确报告数据缺口，不能伪造复权连续性|
|官方SDK支持的包装参数本地也一定支持|先读本地包装范围；不支持的组合报错，不改为联网补抓|

金融数据的口径可能随接口或年份修订。技能帮助定位问题，不能替代当前任务的数据说明及真实账号验收。
