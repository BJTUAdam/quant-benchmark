# 股票池广度与指数趋势分歧时的参与模式和旧仓过渡

> 题目规格包：程序校验与本轮模型交叉审阅已完成；外部API复核未执行，未写入自动接纳库。数据待绑定，运行待接入。

研究目标：当固定研究股票池的上涨广度、分化程度与冻结指数趋势相互冲突时，如何识别未决状态、控制状态切换，并将参与模式的变更分期落实到实际旧仓？研究对象是证据冲突到参与模式及过渡库存的控制流程，不能把指数上涨直接视作所有股票均可增加暴露。

## 运行协议

先在研发期开发首版，再经历七段逐步揭晓的正式期。每段运行时冻结代码；完成后可以保持、调参或修改逻辑。
现金、持仓、未完成订单和JSON memory连续。修改不重置账户，不覆盖过去结果。全部七段的连续账户用于评价。
实际虚拟时间范围、数据版本和分段边界在绑定后确定。

## 研究决策

- 基于已完成的固定池收益、涨跌比例或分化统计，以及当时可见指数序列，研究一致、冲突、样本不足等证据状态。；相互影响：广度只描述已绑定研究池，不声称全市场广度；证据快照传给switch_hysteresis，缺失标的对分母的处理须固定且可追踪。
- 研究确认长度、最短驻留和冲突状态的切换迟滞，保留当前有效状态与待确认状态。；相互影响：只在当日证据冻结后更新一次候选状态，参与模式先使用已生效状态；不得在同日反复重判并重复切换。
- 研究状态映射到趋势参与、回归参与、降低参与或停用的规则，明确冲突与样本不足时是否允许新建仓及存量处置。；相互影响：先读取state_migration恢复的旧模式和未完成过渡，再结合新状态产生目标模式；不得把更换模式视作账户重置。
- 将目标参与模式映射为总暴露、各标的上限和新增额度，研究目标与已有库存不一致时的过渡上限。；相互影响：预算输出给staged_inventory；旧库存超出目标时不能同时把未完成减仓额度再发给新模式新增。
- 研究模式切换时先减旧、同时缓慢调整或等待旧仓退出等过渡方式，考虑T+1、涨跌停及部分成交。；相互影响：按实际成交更新过渡进度；剩余旧仓和未成交单进入state_migration，新模式信号不得重复占用同一笔资金。
- 保存证据版本、当前与候选状态、驻留计数、目标模式、过渡库存和订单占用；参数或逻辑更新时明确兼容和失效条件。；相互影响：每根行情先从账户及旧memory恢复状态，再由participation_policy裁决新增；迁移只改变未来规则，不改历史证据或历史持仓。

可研究的参数与结构选择：

- 股票池广度、分化和指数趋势的特征定义
- 缺失样本、未上市或停牌对广度分母的处理
- 一致与冲突证据的合成和优先级
- 冲突状态的持续性及降级规则
- 状态确认长度与最短驻留
- 趋势、回归、降低参与、停用模式的准入条件
- 参与模式内基础入场和退出表达
- 目标总暴露、单票上限和现金保留
- 旧仓超目标时的新建仓限制
- 模式过渡的分批方式和完成条件
- T+1或涨跌停造成过渡欠账的处理
- 待确认状态及过渡库存的JSON持久化
- 逻辑改版时证据与计数器的兼容判据

持续维护依据：后续阶段可能发生指数趋势与研究池广度长期背离、状态切换密集，或旧模式退出速度跟不上目标模式变化。维护需要区分证据不可靠、迟滞不适当和库存过渡过慢，并选择保持或修改相应模块。所有阶段沿用账户、未成交单和状态memory，保留未决状态及过渡进度。长程复杂度是待验证假设，不承诺每次切换有利。
