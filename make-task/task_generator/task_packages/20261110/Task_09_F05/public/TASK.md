# 跨品种对冲关系的分歧仲裁：可信区间、冻结估计与逐级恢复

> 题目规格包：程序校验与本轮模型交叉审阅已完成；外部API复核未执行，未写入自动接纳库。数据待绑定，运行待接入。

研究目标：当FU/LU等跨品种关系的多个可解释估计口径互相矛盾时，如何区分短期残差偏离、估计失稳与合约换月造成的口径变化，并让冻结估计、降低参与、退出和恢复分别有明确适用状态？研究对象是分歧的仲裁与风险恢复路径，不能把冲突简单平均成一个永远可交易的信号。

## 运行协议

先在研发期开发首版，再经历七段逐步揭晓的正式期。每段运行时冻结代码；完成后可以保持、调参或修改逻辑。
现金、持仓、未完成订单和JSON memory连续。修改不重置账户，不覆盖过去结果。全部七段的连续账户用于评价。
实际虚拟时间范围、数据版本和分段边界在绑定后确定。

## 研究决策

- 仅从当时可见且可交易的实际分合约中确定参与月份，说明期限错配和换月窗口的资格规则。；相互影响：月份变更先生成新关系版本再进入估计；旧月份已有库存仍按旧版本处置，不能把价格拼接跳跃直接当成关系失效。
- 构造至少两种各有明确含义的对冲关系口径及各自的样本资格、估计更新时间和整数手数映射；不预定哪一种口径总是正确。；相互影响：输出估计差异及其可比尺度供监测使用。预算降低可改变可执行整数比例时，保留统计比例与执行比例的区别，不把不可交易手数当成第二个估计器。
- 将估计口径之间的差异、残差表现和实际持仓偏离分别记录，定义证据缺失或冲突，而非一律当作零残差。；相互影响：监测接收真实成交后形成的敞口，再为状态识别提供已完成证据；不得用下一阶段数据事后决定本段估计是否可信。
- 定义可解释且互斥的状态，例如一致、暂时分歧、证据不足和持续失稳，并说明同一事件中多个条件命中时的裁决顺序。；相互影响：先完成当前状态判定，再交由迟滞机制决定是否允许转换；状态可以保留旧估计但必须区分禁止加仓与必须退出。
- 决定分歧出现和消退时的确认、最短驻留及恢复步数，明确状态复核先于预算和下单。；相互影响：恢复需要重新满足估计资格与月份资格，不因一次残差回归就解除暂停；迟滞更新的结果只影响当前决策之后的动作。
- 将已确认状态映射到允许新增、仅减仓或分步恢复的手数上限，按各真实腿独立保证金及费用计算，不假定跨品种抵扣。；相互影响：预算只能限制可执行动作，不能反过来抹掉失稳证据；当整数手数无法满足对冲容差时应选择等待或减仓，而非强制补足风险。
- 在状态和预算共同允许时定义残差参与、保持或退出，说明仅一腿成交、未完成订单与重新估计之间的处理顺序。；相互影响：真实成交后的偏离回到监测。冻结估计时保留版本标记，不能把新估计残差直接应用于旧持仓账本导致无解释的仓位跳变。
- 定义到期前撤旧订单、减旧仓与转入新月份的阶段动作；换月失败时要有明确的保守处理。；相互影响：换月会重新触发月份资格与估计资格核验；新组合尚未建立时，关系状态不能默认恢复为一致。

可研究的参数与结构选择：

- 估计窗口长度与最低有效样本数
- 不同估计口径的更新节奏
- 分歧标准化尺度与证据不足判定
- 失稳进入与恢复退出的独立确认门槛
- 状态最短驻留与分步恢复幅度
- 可执行整数比例误差上限
- 状态对应的新增手数预算
- 残差参与与持有时限
- 到期前停止加仓与撤旧单窗口
- 连续缺失行情时的状态记忆保留方式

持续维护依据：后续阶段可能出现估计口径频繁反向、低流动性月份证据不足、迟滞过慢留下失稳敞口，或恢复过快造成重复开平。每段后可保持原规则、调整确认和预算参数或修改仲裁逻辑，但估计版本、旧仓、未完成订单与memory连续；维护需说明改变影响哪类分歧及为何不依赖未来证据。
