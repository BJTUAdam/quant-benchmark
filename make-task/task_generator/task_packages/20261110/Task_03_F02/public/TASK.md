# 区间参考漂移下的回归目标：目标更新、趋势否决与隔日退出的联动

> 题目规格包：程序校验与本轮模型交叉审阅已完成；外部API复核未执行，未写入自动接纳库。数据待绑定，运行待接入。

研究目标：在区间回归策略中，持仓期间的中心和边界可能自行漂移。如何分辨价格真的回归与目标被动追价，并使目标更新、趋势否决、T+1隔日库存和持有期限共同决定旧仓退出？

## 运行协议

先在研发期开发首版，再经历七段逐步揭晓的正式期。每段运行时冻结代码；完成后可以保持、调参或修改逻辑。
现金、持仓、未完成订单和JSON memory连续。修改不重置账户，不覆盖过去结果。全部七段的连续账户用于评价。
实际虚拟时间范围、数据版本和分段边界在绑定后确定。

## 研究决策

- 研究区间有效期和边界重建，区分区间整体平移、区间宽度变化与真正突破；保存每次持仓建立时的区间版本，不能在持仓后重画历史边缘。；相互影响：区间输出影响reference_estimation与trend_veto；区间版本失效须先传state_migration处理旧仓，不能直接按新区间把旧仓视作新的入场机会。
- 研究回归目标在持仓期间固定、滚动更新或受限移动的方式，并区分价格向目标收敛与目标向价格移动；目标更新只使用已完成数据并保留前后版本。；相互影响：参考目标和更新幅度传deviation_measurement及state_migration；旧目标是否继续约束退出由明确迁移规则决定，不能通过追随价格移动目标而无限延长持有期。
- 在每个参考版本中度量偏离和已实现收敛，分别记录相对创建目标与当前目标的距离，研究何种尺度足以区分真实回归与参考漂移。初次参与资格由当前区间边缘、可见偏离与趋势否决共同形成，研究相应阈值与确认口径；不得根据后续是否回归筛选入场事件。；相互影响：接收range_detection及reference_estimation，输出给trend_veto与exit_policy；两种距离不能混用不同信息窗口，迁移后仍保留原始观测和已发生的持有时长。
- 研究偏离持续扩大时的趋势否决条件，并明确否决是否禁止新建仓、冻结目标更新或要求旧仓退出；不能仅通过把中心移向价格消除趋势证据。；相互影响：接收偏离和区间有效性，约束下一期reference_estimation及overnight_inventory；本事件的目标估计先完成、再判否决，否决对目标更新的限制从下一事件生效，避免同刻循环。
- 研究T+1及下一开盘撮合下的隔日库存：当回归目标在不可卖期间被触及或趋势否决出现时，如何选择仍有效的退出指令及风险等待状态。；相互影响：接收trend_veto和目标版本；实际可卖数量及未完成退出传exit_policy，不能用日线high/low追溯假设盘中已成交，也不能将被锁定部分从风险统计中移除。
- 研究收益实现、偏离回归、目标漂移上限和持有期限之间的退出决策；将价格回归与目标漂移分开报告，研究目标反复移动时是否继续等待。；相互影响：使用deviation_measurement、overnight_inventory和state_migration的一致版本输出退出；真实成交后才减少库存。未完成退出保持跨段待办，不因新参数生效而重新计时。
- 在新阶段改变区间或参考估计时，研究旧仓采用何种目标版本、如何保留持有期限和未完成退出；给出不可换算时的保守处置及对账要求。；相互影响：接收range_detection和reference_estimation的版本变化，将旧目标与新目标的对应关系交给exit_policy；迁移不能覆盖创建时偏离、过去的否决或真实成交。

可研究的参数与结构选择：

- 区间检测和重新建模条件
- 目标固定、滚动或受限移动的规则族
- 参考更新速度与每次移动上限的表达
- 相对创建目标和当前目标的偏离尺度
- 初次参与的偏离门槛、区间边缘条件与确认口径
- 真实收敛与参考漂移的分解方法
- 趋势否决证据及其生效顺序
- 隔日不可卖期间目标触达后的等待策略
- 持有期限和目标漂移上限的联动方式
- 多种退出触发的优先级及去重
- 跨段参考迁移和旧退出待办保留方法

持续维护依据：后续阶段可能出现中心缓慢漂移、区间平移、单边拖行或目标已触达但不可卖的情形。维护需要判断修改参考更新约束、否决边界或隔日退出逻辑，并保持创建目标、持有时钟和待退出库存连续；不能靠更换目标口径把历史未回归的仓位重新标为成功。
