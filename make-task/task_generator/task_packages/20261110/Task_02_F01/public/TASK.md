# 趋势回撤的参考版本与库存层：口径更新后的退出归因和持仓承接

> 题目规格包：程序校验与本轮模型交叉审阅已完成；外部API复核未执行，未写入自动接纳库。数据待绑定，运行待接入。

研究目标：当趋势参考与波动尺度在长程运行中更新时，如何使回撤机会识别、旧库存的建仓理由及新旧参考下的退出判定保持一致，避免仅因重新标度产生重复建仓或伪造失效？

## 运行协议

先在研发期开发首版，再经历七段逐步揭晓的正式期。每段运行时冻结代码；完成后可以保持、调参或修改逻辑。
现金、持仓、未完成订单和JSON memory连续。修改不重置账户，不覆盖过去结果。全部七段的连续账户用于评价。
实际虚拟时间范围、数据版本和分段边界在绑定后确定。

## 研究决策

- 研究趋势参考水平和风险尺度如何随已完成数据更新，并为每次参考更新分配版本；比较旧持仓沿用创建时参考、统一切换新参考或分阶段迁移的研究方案。；相互影响：参考版本传给trend_qualification、pullback_location和state_migration。不同版本须使用共同的当时信息约束；不得用后来的参考值回写过去的趋势资格或建仓理由。
- 在当前参考版本下判定趋势是否继续适用，并区分价格结构被否定与仅参考尺度改变；研究参考更新造成资格变化时是否对已有库存与新机会采用一致口径。；相互影响：接收reference_estimation，输出给pullback_location和exit_policy；旧层是否失效须结合state_migration的映射结果，不把参考重标度自动当成市场趋势反转。
- 研究回撤深度、持续时间和结束证据在参考尺度变化前后的可比表达；同一价格路径不能只因更换标准化窗口被重复识别为新的独立回撤。；相互影响：趋势资格和参考版本决定回撤坐标；输出候选批次给staged_inventory。新旧回撤是否属于同一事件由state_migration持有的历史归属约束。
- 按实际建仓批次记录创建时参考版本、成本、可卖状态及建仓理由，研究新回撤能否增加库存、如何限制旧层与新层的重叠；总量必须与平台真实持仓和成交回报一致。；相互影响：接收pullback_location与state_migration，输出当前可处置层给exit_policy；剩余旧层占用约束capital_allocation，不能通过修改memory把旧仓归零或让锁定库存立即可卖。
- 研究退出触发应来自创建时假设失效、当前趋势否定还是预先定义的持有期限，并明确多原因同时触发时的优先级、去重和批次清退选择。；相互影响：接收trend_qualification、staged_inventory和state_migration；退出结果只在真实成交确认后改变capital_allocation的可用现金及下一期库存，不根据模型层记账假设已经卖出。
- 研究跨段修改参考估计方式时，如何将旧参考和旧库存映射到新口径，同时保留不可重算的创建时事实和退出待办；若不能可靠换算，需给出继续沿用旧版本或明确退出的规则。；相互影响：承接reference_estimation的版本变化，将映射结果送trend_qualification、staged_inventory和exit_policy；迁移在下一阶段初始化后先完成对账，再允许新回撤建仓，避免同一次更新反复触发买卖。
- 在仍受旧参考约束的库存和新参考下的回撤机会之间研究风险额度分配；比较以实际持仓、按层风险或待退出占用衡量可追加量，明确未成交部分的预算归属。；相互影响：旧层及退出待办来自staged_inventory和exit_policy；预算输出约束下一期staged_inventory建仓规模，不能通过降低新参考波动值无条件释放已有旧层风险。

可研究的参数与结构选择：

- 趋势参考的估计族与更新频率
- 风险尺度估计的窗口与异常值处理
- 参考版本生效时点和最短使用长度
- 新旧参考之间的可比映射方式
- 回撤事件重复识别的合并条件
- 按批次或按整体表达风险额度的方法
- 旧层与新层同时存在时的追加限制
- 建仓假设失效与当前趋势否定的退出优先级
- 迁移失败时的保留或退出条件
- 退出待办的跨段对账与重试策略

持续维护依据：后续阶段可能发生参考水平漂移、波动尺度骤变及长期持仓跨越多个参考版本。维护需要判断调整参考估计、限制新旧层重叠或改变迁移方法；任何修改都必须承接旧成本、可卖状态与退出待办。研究记录应区分行情变化引发的决策差异和口径更新引发的差异，不能用重新回测后的历史标签替代实际轨迹。
