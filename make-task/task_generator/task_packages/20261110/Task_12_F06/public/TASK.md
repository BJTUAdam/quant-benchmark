# 同品种双价差共享中间月份：曲线意图归属、净头寸与滚动交接

> 题目规格包：程序校验与本轮模型交叉审阅已完成；外部API复核未执行，未写入自动接纳库。数据待绑定，运行待接入。

研究目标：同一品种至少三个真实月份形成两条共享中间合约的跨期价差时，如何由曲线变化选择相互兼容的价差意图、将其映射到真实合约净头寸，并在部分成交与月份滚动后保持意图归属和风险核算一致？研究对象是多条跨期关系共同控制一个账户，不能把两条理想回测曲线简单相加。

## 运行协议

先在研发期开发首版，再经历七段逐步揭晓的正式期。每段运行时冻结代码；完成后可以保持、调参或修改逻辑。
现金、持仓、未完成订单和JSON memory连续。修改不重置账户，不覆盖过去结果。全部七段的连续账户用于评价。
实际虚拟时间范围、数据版本和分段边界在绑定后确定。

## 研究决策

- 定义不同月份间隔、剩余可交易期限及价格水平的可比表达，明确同一事件使用的月份集合和资料可见时点。；相互影响：选对结果改变可比期限区间，须按同一时间戳的数据重算归一化；不能将未来主力月份选择或期末曲线用于当期标准化。
- 在至少三个当时可用月份上区分共同水平变化、相邻斜率及局部形变，说明缺少某一节点时的等待、降级或退出规则。；相互影响：信号产生多个价差意图而非直接发原子订单。归一化版本改变时，应区分估计值变动与真实持仓变动。
- 从曲线候选中选择可同时参与的两条价差，明确何时允许共享同一实际中间合约、何时只保留一条或全部等待。；相互影响：选择影响归一化和共享腿结构；原有持仓仍占预算，不能只因当前另选两对就丢弃旧合约风险。
- 维护价差级的目标与退出意图，按真实合约代码计算账户净目标，并定义共享中间合约成交向各意图的分配顺序。 影子归属仅作为策略memory内的解释性账本，不构造可独立成交、开平或结算的虚拟子账户；只有真实合约净订单及系统成交能改变平台账户。；相互影响：净头寸抵消不会自动证明两个价差都完成。实际执行的归属残差须进入下一轮信号仲裁，而不是把同一成交同时计入两条价差。 当两意图在共享腿恰好抵消时，记录意图变化但不虚构双方成交，也不将理想价差收益用于系统评分。
- 将净目标转换为逐腿增减仓队列，保留每条价差未完成部分及共享合约的真实仓位；规定撤单、补缺腿与新建仓的顺序。；相互影响：部分成交会改变下一轮各意图的可执行容量和预算。没有完成的组合不能按理论曲线计为完整持仓，单腿风险也不能被影子归属掩盖。
- 对真实合约净额、尚可能成交的订单与过渡敞口计提预算，在两条价差意图之间分配剩余容量。；相互影响：预算约束分步队列并可迫使只保留一条价差；不能重复计算净额抵消带来的可用资金，也不假定跨期保证金抵扣。
- 定义单条价差退出、两条同时退出和意图冲突时如何更新净目标，避免退出一条时无解释地破坏另一条对冲。；相互影响：退出先更新意图账本再交给同一执行队列；成交反馈重建剩余归属，旧订单未撤掉时不能直接用新目标覆盖。 退出或反向动作先与当前真实净仓、可用数量和仍有效订单对账，不能按两份影子头寸重复发送超过实际库存的平仓；开平与反向语义以绑定SDK验收为准。
- 当共享中间月份失去资格或接近到期时，决定平旧结构、迁移共享节点、改成不共享的两对或暂停参与。；相互影响：月份映射变化必须重新选择配对并重算期限；旧中间合约与新中间合约不能视作同一个节点直接抵消。
- 段间维护保存曲线版本、价差意图、成交归属和未完成队列；修改规则时先与账户真实持仓逐项对账。；相互影响：迁移不改变已发生的成交，不重写过去指标；重建后的队列仍经预算、真实月份映射和逐腿执行检查。

可研究的参数与结构选择：

- 曲线样本窗口与最低可用节点数
- 期限/价格归一化尺度
- 共同平移与局部形变的区分规则
- 两条价差同时参与的兼容阈值
- 共享节点资格与仅保留一条的条件
- 价差意图冲突时的优先级
- 共享合约成交的归属顺序
- 未完成意图的超时与撤单机制
- 真实净额、挂单与过渡敞口的预算上限
- 共享中间月份退出时的迁移次序
- 版本迁移中归属账本与实际持仓的对账规则

持续维护依据：后续阶段可能出现共享节点成交归属与实际仓位不一致、两条信号互相抵消造成反复下单、节点换月导致旧意图失配，或预算只允许执行半个目标。每段可按已观察到的偏差维护曲线表达、兼容筛选、归属和调度规则，且账户、真实合约持仓、挂单与JSON memory连续；没有证据时允许保持原逻辑。

## 数据与执行

行情通过Tushare协议桥接器查询。使用环境变量MARKET_BRIDGE_URL和MARKET_BRIDGE_TOKEN，详见DATA_API.md。
名称与代码保持真实；全部时间字段使用虚拟时间，仅表示事件顺序和可见时点。
虚拟年份不对应真实历史年份，不得按年份预设股灾、政策、节假日或未来事件，也不得反推实际时期。
交易日以服务返回日历为准，不按虚拟日期的星期猜测；策略只能根据当时已可见数据形成判断。
只能使用当前可见信息，不访问外网。指数仅用于查询与基准，不可下单。
桥接器按平台传入的阶段范围累计披露；正式策略另受当前事件时钟限制。
显式请求任何未披露日期会整次报TIME_RANGE_EXCEEDED并记录，不能将错误解释为空行情。
AKQuant 0.3.76执行撮合；收盘后决策、下一根行情开盘撮合。期货多腿逐腿撮合，可能部分成交，需处理残余敞口。
交易单位、T+0/T+1、费用、公司行为、价格限制、保证金与结算按绑定后的runtime_profile固定。
资源预算尚未选择，必须由本人先运行finlab setup；CPU、内存和时限由本人明确配置，AI不能代填。
任务只提供非生效的CPU/内存建议；单次运行时限由使用者本人明确选择，不预填。
规则未绑定时不能正式运行。原始价格用于撮合，研究复权数据不得重复计入公司行为收益。
