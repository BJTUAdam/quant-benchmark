# 区间边缘的回归参与与趋势否决

> v2任务规格。规格接纳、数据绑定和运行接入分别记录，当前状态以task_input.draft.json与平台登记记录为准；不要求人工审批。

研究目标：何时仍是区间边缘回归，何时应判定结构进入趋势并停止逆势参与？

## 运行协议

先在研发期开发首版，再经历七段逐步揭晓的正式期。每段运行时冻结代码；完成后可以保持、调参或修改逻辑。
现金、持仓、未完成订单和JSON memory连续。修改不重置账户，不覆盖过去结果。全部七段的连续账户用于评价。
实际虚拟时间范围、数据版本和分段边界在绑定后确定。

## 研究决策

- 研究何种历史结构足以认定当前仍在区间内。；相互影响：结构有效期决定参考水平是否继续适用。
- 研究区间参考水平、边缘及其更新方式。；相互影响：参考水平改变偏离尺度；更新不能抹掉已经发生的亏损。
- 比较偏离边界与波动标准化的回归机会。；相互影响：偏离只有在趋势否决通过时才可参与。
- 研究何时否决逆势入场，并处理区间向趋势的失效。；相互影响：否决应同时考虑旧仓退出，不能只禁止新仓。
- 研究回归完成、时间耗尽和失败退出。；相互影响：T+1限制使退出不能假设当日新仓即时止损。
- 区间失效后何时恢复或重建参考。；相互影响：旧区间memory与新参考版本需明确兼容。

- {"name": "veto_and_recovery", "type": "structured", "description": "否决、持有时限、冷却及恢复条件允许替换逻辑。"}

持续维护依据：后续阶段可能从区间进入趋势；需要维护参考水平、否决条件和恢复规则。维护是否有效须数据和实际轨迹另验。
