# 相对强弱排名、继续持有门槛与换仓缓冲

> v2任务规格。规格接纳、数据绑定和运行接入分别记录，当前状态以task_input.draft.json与平台登记记录为准；不要求人工审批。

研究目标：同一股票池内如何让选入排名、留存门槛、换仓预算和资金分配协同？

## 运行协议

先在研发期开发首版，再经历七段逐步揭晓的正式期。每段运行时冻结代码；完成后可以保持、调参或修改逻辑。
现金、持仓、未完成订单和JSON memory连续。修改不重置账户，不覆盖过去结果。全部七段的连续账户用于评价。
实际虚拟时间范围、数据版本和分段边界在绑定后确定。

## 研究决策

- 定义基于已知量价的相对强弱特征并统一比较尺度。；相互影响：特征尺度影响合成排名和持股集中度。
- 研究多个强弱尺度如何合成以及候选并列处理。；相互影响：排名变化不必立即转成交易。
- 分别研究新选入和继续持有门槛。；相互影响：缓冲影响换手和机会占用。
- 研究单次换仓预算与成本敏感性。；相互影响：预算下优先替换谁，需要综合旧仓和新排名。
- 决定股票权重、闲置现金和集中度。；相互影响：实际T+1可卖量与拒单可能使目标组合无法一步达到。

可研究的参数与结构选择：

- {"name": "relative_strength_features", "type": "structured", "description": "特征、标准化、组合与方向均可研究；不使用未知基本面。"}
- {"name": "ranking_policy", "type": "structured", "description": "持股数、选入/留存门槛、换手与权重相互影响。"}

持续维护依据：市场中强弱持续性、排名稳定性和换手代价可能改变；可维护因子组合、缓冲和资金分配，但不要求每段都修改。
