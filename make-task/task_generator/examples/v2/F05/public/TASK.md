# FU/LU相对关系的滚动对冲和暂停重估

> v2任务规格。规格接纳、数据绑定和运行接入分别记录，当前状态以task_input.draft.json与平台登记记录为准；不要求人工审批。

研究目标：FU/LU关系变化时如何重估对冲、暂停参与并迁移实际双腿头寸？

## 运行协议

先在研发期开发首版，再经历七段逐步揭晓的正式期。每段运行时冻结代码；完成后可以保持、调参或修改逻辑。
现金、持仓、未完成订单和JSON memory连续。修改不重置账户，不覆盖过去结果。全部七段的连续账户用于评价。
实际虚拟时间范围、数据版本和分段边界在绑定后确定。

## 研究决策

- 研究FU/LU月份匹配与共同可交易条件。；相互影响：月份选择改变对冲关系和移仓成本。
- 仅用历史估计滚动对冲关系并转成整数手数。；相互影响：残差信号和真实腿名义敞口不能混用。
- 研究残差参与、退出、止损和时间限制。；相互影响：信号变化需落实为真实腿目标，不能买卖负价差本身。
- 研究何时判定关系失效、暂停和重估。；相互影响：重估改变对冲比例，必须明确处置旧腿。
- 按乘数、费用和保证金计算组合手数。；相互影响：预算、逐腿部分成交和残余敞口会改变信号实际实现。
- 关系版本更新和换月时处理旧仓及memory。；相互影响：只有未来决策采用新定义，过去正式结果不可重写。
