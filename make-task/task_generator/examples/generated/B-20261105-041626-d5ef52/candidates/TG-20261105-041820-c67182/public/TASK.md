# 跨品种加工链条的关系重估与残差腿组合：月份选择、对冲比例、分项信号汇总与保证金预算的联合维护

> v2任务规格。规格批准、数据绑定和运行接入分别记录，当前状态以task_input.draft.json与平台登记记录为准。

研究目标：在国内期货真实分合约日线环境中，仅使用已完成交易日收盘后可见的字段：如何在两个不同品种之间估计当时可见的滚动对冲关系（含合约乘数与整数手数约束），并根据当时已知的剩余期限和流动性选出实际参与的两条合约腿；当残差偏离达到参与条件时，如何以真实有符号手数建仓并逐腿撮合、容许部分成交与残余敞口；当关系残差尺度或对冲比例发生变化时，如何判定关系失效、暂停参与并重新估计，而不是把普通波动当作关系断裂；双腿保证金占用与费用随价格、保证金率和手数变化时，如何在预算约束下决定配对手数、缩减或退出；版本更新或重新估计后，如何迁移旧腿、未成交换腿与已确认的对冲比例版本，使分段研发中头寸与状态连续可核？

## 运行协议

先在研发期开发首版，再经历七段逐步揭晓的正式期。每段运行时冻结代码；完成后可以保持、调参或修改逻辑。
现金、持仓、未完成订单和JSON memory连续。修改不重置账户，不覆盖过去结果。全部七段的连续账户用于评价。
实际虚拟时间范围、数据版本和分段边界在绑定后确定。

## 研究决策

- 在两个已支持品种的可交易合约集合中，仅用当时已收盘且已发布的剩余期限、成交活跃度与价格刻度，决定本期实际参与的两条合约腿；须处理某腿临近到期或流动性迁移时的候选更替，并把候选集合与选择依据作为可核状态保存，不交易合成价差或连续拼接价。；相互影响：选出的两腿直接决定hedge_estimation可比的价格序列与合约乘数口径；state_migration回指本模块，要求迁移时重新评估旧腿是否仍在候选集合内，从而让上月确认的配对不自动沿用。
- 在选定两腿的已完成日线序列上估计当时可见的滚动对冲比例，处理两品种计价单位、合约乘数差异与整数手数取整规则；输出对冲比例及其可信区间、取整后的残余敞口估计，并按固定节奏或事件触发重估，不引用未来数据。；相互影响：接收month_selection的腿集合后产出残差定义，供entry_exit判定参与；relationship_monitoring判定关系失效时回指本模块触发重估并改变残差口径，重估结果又改变entry_exit的参与阈值含义。
- 依据当前残差水平与波动标准化后的偏离尺度，决定是否参与、方向与真实有符号手数；逐腿下单并记录逐腿成交、部分成交与残余敞口，退出条件考虑价差收敛、持有时限与关系状态，未成交残余须在后续可执行时点处置。；相互影响：依赖hedge_estimation给出的比例与残差口径确定参与规模；退出与残余敞口的处置结果进入relationship_monitoring作为关系变化的证据来源，并影响margin_budget占用的释放节奏。
- 持续监控残差尺度、对冲比例稳定性与两腿流动性是否偏离估计窗口所描述的关系；区分残差扩大属于正常波动还是关系断裂，据此输出暂停参与、维持参数或触发重估的状态，并记录判定依据与生效时点。；相互影响：接收entry_exit退出证据与本模块自身的偏离度量，输出暂停或重估决定；重估回指hedge_estimation，暂停则约束margin_budget只在处置旧腿范围内使用预算。
- 按真实腿的价格、合约乘数、保证金率候选与费用估计，将可用资金映射为每腿可下单手数与预算上限；缩减时按可成交约束分步处理，优先释放流动性较好一腿并记录残余敞口，禁止在预算不足时新开双腿。；相互影响：接收relationship_monitoring的暂停或恢复状态决定预算是否可用于新开仓；预算与手数结果进入state_migration作为迁移时必须保留的占用基线。
- 在重新估计、合约更替或版本更新时迁移两腿持仓、未完成订单、残余敞口、对冲比例版本与预算占用基线；迁移规则须与已确认的腿选择兼容，处置无法对应的旧腿并把处置结果写入持久化状态。；相互影响：回指month_selection，要求迁移后旧配对重新通过候选筛选；承接margin_budget的占用基线，使下一段预算计算不会重复占用或遗漏已挂未成交单。

可研究的参数与结构选择：

- 滚动估计窗口长度（辅助参数，不替代关系估计设计）
- 残差偏离的波动标准化方式与参与阈值档位
- 整数手数取整规则与残余敞口容忍上限
- 关系失效判定的连续确认次数与暂停时长
- 预算占用的安全边际与逐腿缩仓顺序规则
- 对冲比例重估的固定节奏与事件触发条件

持续维护依据：后续揭晓的已完成交易日数据可能显示对冲比例漂移、残差尺度变化或某腿流动性迁移。若对冲比例在重估窗口内仍稳定且残余敞口可控，应保持参数与逻辑；若残差尺度持续超出估计区间，应调整关系失效判定与暂停条件；若某腿频繁因流动性或到期被迫更替，则需修改month_selection与state_migration的衔接逻辑。核心维护对象是关系漂移与保证金暴露：真实腿敞口、费用与保证金变化会改变可承受手数，旧题的固定比例或固定手数做法可能不再适用。本任务不承诺每次维护提升收益，也不要求实盘盈利。
