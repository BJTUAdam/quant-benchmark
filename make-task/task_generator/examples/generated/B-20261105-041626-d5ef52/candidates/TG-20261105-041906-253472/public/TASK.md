# 期货趋势回撤中的资格复核、回撤定位与分批库存连续维护

> v2任务规格。规格批准、数据绑定和运行接入分别记录，当前状态以task_input.draft.json与平台登记记录为准。

研究目标：在国内期货真实分合约日线环境中，仅使用已完成交易日收盘后可见的字段，如何在单个品种上确认既有趋势仍然适用，并把回撤深度与回撤结束的判定转化为可按真实整数手数、逐腿撮合参与的分批建仓节奏；当退出条件触发或趋势资格被撤回时，如何对已建批次逐批处置并处理未成交与残余敞口；处置后的资金预算缩减与保证金占用变化又如何反过来收窄下一段趋势资格的判定宽度与可接受的回撤容差，使资格、定位、库存、退出与预算在同一跨段状态中连续可核？

## 运行协议

先在研发期开发首版，再经历七段逐步揭晓的正式期。每段运行时冻结代码；完成后可以保持、调参或修改逻辑。
现金、持仓、未完成订单和JSON memory连续。修改不重置账户，不覆盖过去结果。全部七段的连续账户用于评价。
实际虚拟时间范围、数据版本和分段边界在绑定后确定。

## 研究决策

- 仅用已完成收盘数据识别当前品种是否存在可继续适用的趋势，并显式定义资格被撤回的可观察条件；资格判定必须输出可审计的判定记录，接受由资金预算回压带来的有效宽度变化。；相互影响：为回撤定位提供前提；同时接收资金分配回传的预算宽度，使资格判定不是静态阈值。
- 在已确认趋势内定位回撤深度与回撤结束，处理参考水平随合约切换的重建；输出回撤是否结束以及可供分批建仓的相对位置。；相互影响：依赖趋势资格；其结论直接决定分批库存的启动与批次节奏，并受退出后预算缩减的影响。
- 把回撤定位结论转化为真实有符号整数手数的分批建仓与分批退出，逐腿撮合，允许部分成交与残余敞口，并记录每批次的成本与保证金占用。；相互影响：依赖回撤定位；批次状态供退出政策判断，并接收资金分配给出的手数与预算上限。
- 定义止损、趋势资格撤回、持有时限与跟踪退出的优先与去重规则，确保同一失效不会被重复计为多次减仓，并给出未成交换腿与残余敞口的处置顺序。；相互影响：消费分批库存状态；其减仓结果与费用去向资金分配，并触发预算缩减。
- 在真实腿风险、保证金、费用与已占用预算下分配手数与现金，决定缩减后下一段的可用预算与单品种敞口上限。；相互影响：由退出政策触发缩减；其预算结果回指趋势资格的有效宽度与回撤容差，并约束分批库存的可用手数，形成闭环。

可研究的参数与结构选择：

- 趋势资格确认所需的最短完成观测长度
- 回撤深度相对参考水平的容差
- 分批建仓的批次数与每批手数比例上限
- 退出优先级与失效去重的时间窗
- 预算缩减的档位数量与恢复所需的持续观测长度
- 单品种敞口上限占可用预算的比例

持续维护依据：后续分段揭晓的数据可能显示趋势结构在合约切换后失效、回撤深度超出原容差、分批建仓的实际成交与信号出现偏差，或预算缩减后保证金占用仍与目标不符。这些信号分别触发对结构有效性、信号与执行差异、风险恢复节奏和跨段状态兼容的复查；据此可能保持现有逻辑、调整参数，或修改模块之间的判定与回压关系。维护不保证改善收益，也不承诺盈利。
