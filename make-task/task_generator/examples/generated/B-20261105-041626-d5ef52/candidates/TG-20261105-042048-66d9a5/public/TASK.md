# B/M/Y加工链条的分项信号冲突裁决与真实腿库存交接

> v2任务规格。规格批准、数据绑定和运行接入分别记录，当前状态以task_input.draft.json与平台登记记录为准。

研究目标：在国内期货真实分合约日线环境中，仅使用已完成交易日收盘后可见的字段：如何当时可见地选定B、M、Y三条实际合约腿并估计加工关系下的整体系数与整数手数；当整体加工价差信号与分项（豆油/豆粕相对豆粕等分项偏离）信号彼此冲突时，如何裁决一致性并转化为真实有符号手数的参与、退出与持有时限；当双腿或多腿保证金占用、费用与价格变动使预算收紧时，如何决定各腿手数、缩减与残余敞口的处置；版本更新或合约临近到期时，如何把已确认的系数版本、候选腿集合与未完成部分成交状态迁移到下一段，使分段研发与跨段记忆连续可核？

## 运行协议

先在研发期开发首版，再经历七段逐步揭晓的正式期。每段运行时冻结代码；完成后可以保持、调参或修改逻辑。
现金、持仓、未完成订单和JSON memory连续。修改不重置账户，不覆盖过去结果。全部七段的连续账户用于评价。
实际虚拟时间范围、数据版本和分段边界在绑定后确定。

## 研究决策

- 仅用已完成收盘数据，在B、M、Y各自当时可交易的到期月份中选出本期三条实际合约腿，依据当时已知的剩余期限与成交持仓活跃度排序，不使用任何事后信息；被选中的候选腿集合必须作为可迁移状态记录，而不是每段重新自由选择。；相互影响：候选腿集合直接决定hedge_estimation在哪些真实价格序列上估计加工关系与整数手数；当state_migration回写month_selection时，迁移后的候选集合不得自动沿用旧腿，须重新确认，否则系数版本与实际价格序列对不上。
- 在已选出的B、M、Y真实合约腿上估计当时可见的加工关系系数与偏离残差尺度，处理不同品种价格刻度、合约乘数与整数手数带来的不可整除问题；系数与残差尺度须带版本号，避免不同腿组合下的估计混用。；相互影响：估计出的系数版本与残差尺度是signal_aggregation合成整体与分项信号的共同分母；腿组合变更或关系漂移会改变该分母，从而改变信号的含义与参与阈值。
- 把整体加工价差信号与分项信号（按当时可见的腿价与已确认系数计算的偏离方向与强度）合成一致的可执行判断；当整体与分项方向冲突时，须明确优先级与降级规则，冲突未裁决时不得生成新参与，而不是简单平均或取多数。；相互影响：信号合成结果决定entry_exit的参与与退出条件；而month_selection换腿或hedge_estimation更新系数版本时，分项信号的可比性被改变，冲突裁决规则必须随之复核，不能沿用旧阈值含义。
- 在真实分合约上以有符号整数手数建立、加、减与退出，逐腿撮合、可部分成交并保留残余敞口；定义持有时限与失效退出，并明确多腿退出顺序与未成交部分在下一段的处理，而不是假设原子成交。；相互影响：参与与退出直接产生保证金占用与费用，构成margin_budget的输入；退出后残余敞口与未完成订单又必须由state_migration承接，否则下一段会重复下单或遗漏对冲腿。
- 按各腿真实风险、费用与保证金占用分配手数，并在占用接近预算上限时决定缩减哪一腿、缩减多少整数手以及是否暂停新增；预算约束须与实际逐腿成交结果一致，而不是按名义价差计算。；相互影响：预算紧约束会反过来限制entry_exit可执行的腿数与手数，形成残余敞口；预算状态与占用差额需要state_migration迁移，且迁移后的预算口径若变更须重新映射已建腿。
- 在版本更新、系数重估或合约临近到期时，迁移已确认的系数版本、候选腿集合、各腿实际手数、未成交订单与预算占用；明确哪些旧状态不得自动沿用（如旧腿组合下的系数直接套用到新腿），并规定迁移失败时保留而是继续承接旧腿。；相互影响：迁移结果是下一段month_selection与hedge_estimation的起点，使腿集合与系数版本状态连续；同时迁移须与margin_budget的占用口径保持一致，避免预算已释放但实际仍有残余敞口。

可研究的参数与结构选择：

- 加工关系滚动估计窗口长度
- 残差偏离参与阈值与退出阈值
- 整体与分项冲突时的优先级规则
- 候选月份的剩余期限下限与活跃度下限
- 单腿与总保证金预算上限
- 持有时限与冷却期
- 系数版本与腿集合的迁移不沿用规则参数

持续维护依据：后续揭晓的观察可能来自三处：加工关系系数与残差尺度漂移（hedge_drift），真实多腿保证金占用与费用变化（margin_exposure），以及合约到期与移仓导致的腿集合变更（expiry_roll）。这些观察出现时，研究者可能需要保持、调参或改逻辑：若系数版本更新后分项与整体信号仍一致且预算占用稳定，可保持；若残差尺度漂移使分项信号可比性下降，则需重估系数或调整冲突裁决规则；若某腿临近到期导致候选集合变化，则须迁移已建腿并重新确认整数手数。此处不承诺每次维护提升收益，也不要求实盘盈利；维护只表示成员集合，顺序不影响含义。state_compatibility要求版本间持仓、现金、订单与memory连续兼容。

## 数据与执行

行情通过Tushare协议桥接器查询。使用环境变量MARKET_BRIDGE_URL和MARKET_BRIDGE_TOKEN，详见DATA_API.md。

虚拟年份不对应真实历史年份，不得按年份预设股灾、政策、节假日或未来事件，也不得反推实际时期。
交易日以服务返回日历为准，不按虚拟日期的星期猜测；策略只能根据当时已可见数据形成判断。
只能使用当前可见信息，不访问外网。指数仅用于查询与基准，不可下单。

交易单位、T+0/T+1、费用、公司行为、价格限制、保证金与结算按绑定后的runtime_profile固定。
资源预算尚未选择，必须由本人先运行finlab setup；CPU、内存和时限由本人明确配置，AI不能代填。
任务只提供非生效的CPU/内存建议；单次运行时限由使用者本人明确选择，不预填。
规则未绑定时不能正式运行。原始价格用于撮合，研究复权数据不得重复计入公司行为收益。
