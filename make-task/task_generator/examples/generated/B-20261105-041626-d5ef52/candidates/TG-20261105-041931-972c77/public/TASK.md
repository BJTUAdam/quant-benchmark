# 区间边缘放量冲击的恢复路径：冲击识别、回摆与延续的区分、隔日库存处置与失效停用

> v2任务规格。规格批准、数据绑定和运行接入分别记录，当前状态以task_input.draft.json与平台登记记录为准。

研究目标：在国内股票与ETF日线环境中，仅用当时已收盘可见的价量数据，如何先在已完成数据上界定区间有效期与边界，再把区间边缘的异常价量冲击与普通波动区分开；冲击后如何判定恢复路径处于回摆、延续还是未决，并据此决定是否等待确认后入场；入场后无法当日卖出的隔夜库存与已挂未成交单如何处置，冲击路径被证伪时如何定义机制失效、退出、暂停事件识别并在冷却后恢复，使参考水平随区间漂移可更新且跨段持仓与记忆连续可核？

实际虚拟时间范围、数据版本和分段边界在绑定后确定。

## 研究决策

- 仅用已完成日线收盘数据界定区间边界、有效期与更新规则，并输出当前是否处于有效区间状态；不使用未来数据，区间失效或重建须记录时点。后续已揭晓的区间外延续会促使收紧有效期或提高重建门槛。；相互影响：为冲击识别提供背景：只有在有效区间边缘附近发生的异常价量波动才进入冲击候选，避免把全样本普通放量混入；区间重建时须同步重置参考水平。
- 在区间边缘上定义异常价量冲击的识别条件（如相对已完成数据的量能与价格偏离尺度），区分冲击事件与普通波动，并记录事件起点与可见时点。后续观察显示大量事件并未发生回摆时，应调整识别口径而非仅改阈值。；相互影响：依赖区间状态限定候选位置；其事件定义直接决定恢复路径的判别起点与确认等待长度，并接收失效退出回写的降级信号以暂时提高识别门槛。
- 在冲击后若干已完成交易日上判断路径处于回摆、延续还是未决，定义各状态的转移与可参与条件。若已揭晓路径多为延续，需改判逻辑而非单纯延长等待。；相互影响：由冲击事件发起，向确认环节输出路径状态；同时接收区间检测更新，区间失效时已判定的回摆路径须降级为未决。
- 定义在路径判定为回摆时等待何种完成数据确认方可入场，以及确认失败时不入场的处理。已揭晓的确认后仍反转会促使改确认证据组合。；相互影响：把恢复路径状态转化为可成交入场动作，并把可入场方向写入隔日库存约束；同时受冲击识别口径变化影响确认窗口的起点。
- 处理T+1不可卖约束下的隔夜库存：入场时点与数量须使当日新增不可卖部分与已挂未成交单可被后续退出政策承接，包含库存分层与不可用现金预留。；相互影响：约束入场可执行规模，并把隔夜库存与未完成订单清单传递给失效退出，使退出顺序与可卖数量相容。
- 定义冲击路径被证伪、区间结构失效或隔夜库存超出可承受敞口时的退出与暂停规则，包括冷却与恢复条件；退出后回写冲击识别与区间检测以调整后续识别门槛。后续揭晓的反复失效会促使改失效判据而非仅调止损。；相互影响：接收隔夜库存状态执行退出，并回写冲击识别与区间检测，形成闭环；不得承诺每次维护提升收益。

可研究的参数与结构选择：

- 区间有效期与边界更新窗口（仅使用已完成数据）
- 区间边缘带宽与偏离标准化口径
- 冲击识别的量能倍数与价格偏离尺度阈值
- 恢复路径判定的状态滞后与未决持续长度
- 入场确认的等待完成数据根数与确认证据组合
- 隔夜库存上限与不可卖部分的风险预留比例
- 失效退出的触发条件、冷却长度与恢复门槛
- 区间重建与冲击识别门槛的联动降级幅度

持续维护依据：后续分段研发中，区间边界与参考水平会随已揭晓数据漂移，冲击事件定义与路径判别可能出现系统性失效；需分别维护参考漂移、回归假设失效、信号与实际可成交持仓差异以及跨段状态兼容。维护动作可为保持、调参或改逻辑，均不保证提升收益，也不以实盘盈利为目标。
