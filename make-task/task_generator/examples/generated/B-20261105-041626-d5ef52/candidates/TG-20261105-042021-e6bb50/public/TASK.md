# 风险预算的回撤证据等级与恢复准入：预算档位下调、未成交待办清理与分步回升

> v2任务规格。规格批准、数据绑定和运行接入分别记录，当前状态以task_input.draft.json与平台登记记录为准。

研究目标：在国内股票与ETF日线环境中，仅用当时已收盘的价量与账户信息：如何把组合层面的已回撤幅度、近期已实现波动与暴露集中度整理成带证据等级的风险判断，使同一段回撤与同一类风险来源不被重复计为多档下调；该判断如何映射到可审计的预算档位，并在下调触发时按当时可成交约束（T+1不可卖库存、单票权重上限、现金不足）决定下到哪一档以及哪些未成交待办随之失效；下调后现金碎片与剩余仓位的实际占用，又如何改变下一段风险证据的读取口径与可信等级，使恢复准入读取的是调整后的占用而非被覆盖前的记忆？

## 运行协议

先在研发期开发首版，再经历七段逐步揭晓的正式期。每段运行时冻结代码；完成后可以保持、调参或修改逻辑。
现金、持仓、未完成订单和JSON memory连续。修改不重置账户，不覆盖过去结果。全部七段的连续账户用于评价。
实际虚拟时间范围、数据版本和分段边界在绑定后确定。

## 研究决策

- 仅用已完成交易日收盘后可用的价格、成交与账户字段，把组合已回撤幅度、近期已实现波动和暴露集中度整理为带来源标签与可信等级的风险证据；同一回撤来源在一段内只计一次，需给出优先与去重规则，并把当时被缩减后的实际仓位占用作为下一段读取口径。；相互影响：为 risk_budget 提供分级证据输入；同时接收 drawdown_response 执行结果与 capital_allocation 占用结果回写，使缩减后的仓位碎片改变证据的可信等级而非沿用原判定。
- 把带可信等级的风险证据映射为可审计的预算档位（含名义暴露上限、现金留存与单票集中度三个可选项的组合表达），明确档位边界与占用计量方式；档位表达的选择本身须可解释其可执行性，而不是仅作阈值比较。；相互影响：依赖 state_identification 的证据等级；输出档位目标给 drawdown_response；档位占用计量口径与 capital_allocation 的现金碎片结果对齐，避免目标与占用不同度量。
- 依据档位目标与当前真实持仓决定下调幅度阶梯与执行顺序：先识别可卖与不可卖部分，撤销与档位语义冲突的未成交挂单，在现金不足一次性合规减仓时给出分步处置与残余敞口记录；执行结果回写 state_identification。；相互影响：消费 risk_budget 的档位差；产生实际占用与未成交待办余额供 recovery_policy 判定回升条件，并回写 evidence 使缩减结果参与下一段证据。
- 定义分步回升准入：回升所需证据须独立于被覆盖的回撤记忆，按档位逐级而非一次性回到原档；清晰记录每级上调的占用门槛、最短间隔与撤回条件，并说明回升判断与未清待办的关系。；相互影响：依赖 drawdown_response 后的实际占用与待办余额；输出可用预算给 capital_allocation，使回升速度受可执行性约束而非仅受价格条件约束。
- 在回升后的可用预算下分配资金与现金，处理T+1新增库存、单票权重上限导致的仓位碎片与剩余现金；明确碎片化程度如何反馈为下一期预算占用与证据读取口径的一部分。；相互影响：消费 recovery_policy 给出的可用预算；输出占用与碎片结果回指 state_identification 的读取口径，并约束 risk_budget 档位目标的可达性，形成闭环。

可研究的参数与结构选择：

- 风险证据来源的组合与权重结构（不含具体取值）
- 证据可信等级的划分方式与去重规则
- 预算档位表达选择：名义暴露上限、现金留存、单票集中度
- 档位下限与档位间步长结构
- 缩减执行的分步顺序与未成交挂单撤销规则
- 回升所需独立证据类型、每级间隔与撤回条件
- T+1不可卖库存与现金不足时的处置优先级
- 现金碎片与剩余现金对证据读取口径的反馈方式

持续维护依据：后续分段揭晓的观察若显示同一回撤被多次计档或档位下调无法按当时可卖约束执行，说明证据去重与执行顺序需要调整；若回升长期停留在低档或反复触发下调，需要保持或改写恢复准入的间隔与占用门槛，而非仅调数值。每次维护须核验跨段现金、持仓、未完成订单与JSON memory连续，并检查缩减未完成部分是否被下一段误计为已达成目标；不保证维护必然提高收益。
