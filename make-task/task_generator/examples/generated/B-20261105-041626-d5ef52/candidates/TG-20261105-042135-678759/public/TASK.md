# 期货单品种趋势回撤中的资格复核与预算耦合库存：逐腿撮合下的分批建仓、资格撤回与退出联动

> v2任务规格。规格批准、数据绑定和运行接入分别记录，当前状态以task_input.draft.json与平台登记记录为准。

研究目标：在国内期货真实分合约日线环境中，仅使用已完成交易日收盘后可见的字段，如何在单个品种上确认既有趋势仍然适用、把回撤深度与回撤结束的判定转化为可按真实整数手数逐腿撮合参与的分批建仓节奏；当退出条件触发或趋势资格被撤回时，如何对已建批次逐批处置并处理部分成交与残余敞口；处置后的预算缩减与保证金占用变化又如何反过来收窄下一段趋势资格的判定宽度与可接受的回撤容差及可用批次手数，使资格、定位、库存、退出与预算在同一跨段状态中连续可核？

## 运行协议

先在研发期开发首版，再经历七段逐步揭晓的正式期。每段运行时冻结代码；完成后可以保持、调参或修改逻辑。
现金、持仓、未完成订单和JSON memory连续。修改不重置账户，不覆盖过去结果。全部七段的连续账户用于评价。
实际虚拟时间范围、数据版本和分段边界在绑定后确定。

## 研究决策

- 仅用已完成交易日收盘数据，界定单品种既有趋势的方向、成立时长与继续适用的条件，并明确趋势资格何时需要复核撤回；不使用未来数据、不预设真实年份事件。；相互影响：为回撤定位提供方向与前提，并接受资金分配的预算回压来调整资格判定的有效宽度；资格撤回本身不构成独立决策，而是并入退出政策与回撤定位的状态更新。
- 在趋势资格成立的前提下，用当时可见的已完成价格与成交活跃度定位趋势内回撤的深度区间及回撤结束的可观察标志；区分正常回撤与趋势结构失效。；相互影响：接收趋势资格给出的方向与容差，其回撤结束判定触发分批库存节奏；回撤容差又受资金分配的预算回压影响，资格撤回时其状态需被退出政策吸收更新。
- 把回撤结束的判定转化为按真实分合约有符号整数手数的分批建仓与分批退出库存安排；在逐腿撮合、可部分成交的约束下记录已成交批次、未成交部分与残余敞口。；相互影响：由回撤定位触发建仓批次与顺序，向退出政策暴露批次库存与残余敞口；同时受资金分配约束的可用手数上限与保证金占用影响，实际建仓规模反馈给预算。
- 定义止盈、止损、持有时限与跟踪退出条件，并明确当退出条件触发、趋势资格被撤回或前一批次止损时，对已建批次逐批清退的顺序与未成交单处置；在部分成交与残余敞口下按腿给出可执行退出。；相互影响：接收分批库存的批次与残余敞口作为退出对象，其退出结果把释放的现金与已实现盈亏传递给资金分配；同时吸收趋势资格撤回与回撤失效两类证据，避免与回撤定位重复触发。
- 在真实分合约保证金占用、费用与整数手数约束下，决定单品种上各批次可用手数与现金预算；当清退或连续止损后按预算缩减，随后依据恢复条件逐步回升。；相互影响：接收退出政策释放的现金与实现盈亏，将预算回压到趋势资格的判定宽度与可接受回撤容差，以及分批库存的可用批次手数上限，形成预算—资格—库存的闭环。

可研究的参数与结构选择：

- 趋势资格的方向确认参数与最短成立长度的可选范围
- 回撤深度区间的下界与上界的可选范围
- 批次数量与每批可用手数上限的比例参数
- 预算缩减与恢复的分档比例参数
- 退出政策的跟踪退出放宽量可选范围
- 冷却期间长度参数

持续维护依据：后续段落揭晓的已收盘数据可能显示：原先认定的趋势结构在回撤后不再成立，或回撤定位反复被证伪，或逐腿撮合造成的残余敞口使实际库存偏离信号意图。这些观察可能促使维护者保持现有逻辑（若资格撤回与退出政策仍能一致吸收失效且预算回压稳定）、只调参数（若仅是回撤容差或批次手数上限需要重校）、或修改逻辑（若趋势资格的撤回无法被退出政策可靠吸收，或预算回压导致资格判定失去意义、库存与预算互相锁死）。维护不承诺每次调优都提升收益，也不要求实盘盈利；未成交、部分成交与残余敞口需在段间可见后才可判断信号与执行差距。
