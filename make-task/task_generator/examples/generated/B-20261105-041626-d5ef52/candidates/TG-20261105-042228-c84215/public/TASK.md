# 相对强弱排名的候选池边界协商：流动性资格集合、留存门槛与换仓预算的联合维护

> v2任务规格。规格批准、数据绑定和运行接入分别记录，当前状态以task_input.draft.json与平台登记记录为准。

研究目标：在国内股票或ETF日线环境中，仅用当时已收盘的量价与复权数据：如何用同一完成窗口定义可比的相对强弱特征，并先以成交活跃度界定可参与排名的候选集合；当同刻排名触发替换时，买入门槛与继续持有门槛如何分设以保留既有持仓；T+1新买不可卖库存、已挂未成交单、单票权重上限与现金余额如何共同限制本期可换仓额度，而换仓额度与现金碎片化的执行结果又如何反过来收紧或放宽下一期可参与排名的流动性资格集合与留存门槛有效宽度，使留存名单在排名噪声、换仓可执行性与流动性边界之间保持可解释、可跨段接续？

## 运行协议

实际虚拟时间范围、数据版本和分段边界在绑定后确定。

## 研究决策

- 仅用已完成日线收盘数据与已发布复权因子，定义同一完成窗口内的相对强弱特征：收益口径需统一（复权后价格、相同回看长度与跳空处理），使不同股票在同刻可比；同时明确特征对停牌、缺bar和价格限制日的可见处理规则，不引入未来收益或成分信息。；相互影响：产出的可比特征向量直接决定 liquidity_filter 的活跃度度量口径与 rank_aggregation 的输入分布；若窗口口径改变，流动性集合与排名分母须同步重建，因此该决策为后续两项排名前输入的共同前置。
- 依据排名前已知的成交活跃度与可交易状态（按当时可成交性而非事后信息）界定可参与排名的候选集合，并给出集合成员进出时的过渡规则；须明确该集合由资本分配执行结果反向收缩或恢复的准入条件，而非一次性入池。；相互影响：与 feature_definition 共享完成窗口口径，向 rank_aggregation 提供排名分母；同时接收 capital_allocation 的反向回指——当期仓位碎片化与剩余现金不足时收缩可参与集合，使排名分母随预算结果变化。
- 在当前流动性候选集合内合成同日排序得分，明确各特征的方向、标准化方式与合成一致性要求；得分只依赖当日及之前已完成数据，并保留排序不确定度以便后续门槛使用。；相互影响：输入同时来自 feature_definition 与 liquidity_filter，输出排序与候选队列供 holding_buffer 与 turnover_budget 使用；集合边界一变，同刻排名分母与保留次序随之改变。
- 分别设定买入入选门槛与继续持有门槛，使已持仓在排名下滑时获得留存缓冲；缓冲宽度随时间与当期可换仓能力调整，而非固定名次。；相互影响：接收 rank_aggregation 的排序结果决定留换；同时受 capital_allocation 回指约束，当现金与权重上限使新买不可执行时，留存门槛的有效宽度被放宽以避免无意义换仓。
- 在已识别候选替换与成本条件下设定单期换手额度与换仓预算，明确T+1新增库存与已挂未成交单占用的额度扣减顺序，以及超额候选的延后机制。；相互影响：由 holding_buffer 的留换集合决定须执行的换仓量，并受资本分配结果约束实际可动用额度；其可用额度又反馈资本分配，使预算与留存缓冲相互让步。
- 在多个候选机会间分配资金与现金预算，处理单票权重上限、整数交易单位、现金留存与未完成订单占用；并明确分配执行结果如何回写下一期的流动性资格集合与留存门槛。；相互影响：接收 turnover_budget 的可执行换仓量决定实际下单，同时向 liquidity_filter 与 holding_buffer 回指：碎片化仓位与现金不足收缩下一期候选集合、放宽留存门槛，形成预算—资格—留存的双向协商闭环。

可研究的参数与结构选择：

- 特征回看窗口长度与跳空处理选项
- 活跃度门槛与候选集合规模上下限
- 买入入选名次与继续持有名次之差（留存缓冲宽度）
- 单期最大换手比例与换仓候选延后数量
- 单票权重上限与最低现金留存比例
- 集合收缩或恢复的过渡迟滞长度

持续维护依据：后续分段揭晓的已完成数据可能显示：排名在相邻交易日频繁换位、留存名单变动仍偏高，则需考虑加宽继续持有门槛或调整特征窗口；若已实现换手成本与买卖价差对结果的分摊偏高，则须考虑收紧换仓预算或改变额度扣减顺序；若流动性候选集合成员频繁进出导致名单跳变，则须检查集合过渡规则是否应带迟滞而非直接跟随预算回指。这些观察可能促使保持现有逻辑、仅调参数或改动模块间关系，但不保证每次维护提升收益，也不要求实盘盈利。
