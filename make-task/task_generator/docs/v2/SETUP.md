# 首次使用：由本人选择运行资源

安装后，使用者本人先在终端运行：

```powershell
finlab setup
```

该命令逐项要求明确输入：两容器合计CPU数、内存MB数、单次运行时限。2CPU与4096MB仅为推荐，不预填、不按回车采纳。时限没有默认或推荐值；输入正整数秒，或明确输入none表示不限时。最终输入“本人确认”才保存，取消或中断不会写入新配置。

AI不能选择这些值、代填交互或生成本人确认文件。AI遇到SETUP_REQUIRED时应报告缺少本人配置，并将该步骤留给实际使用者。系统通过交互终端检查和显式确认落实此规范，不宣称可以鉴别真人与AI。

本机文件为.finlab/operator.json，不包含凭证，不随源码或任务包分发。新解压的工具包没有已确认预算。CLI启动合成演示、创建episode、运行回测或执行Docker验收前会检查配置；离线文档、规格检查和静态提交预检可以直接使用。

创建episode时将选择冻结到运行契约；两容器各分一半CPU与内存。后续重新setup只影响新episode，不修改已冻结任务。资源与契约冲突时停止，AI不能覆盖。已取消--timeout命令参数。

未绑定任务的resources为null，resource_status为requires_human_setup。绑定后resources是完整对象：timeout_seconds为正整数表示限时，为null表示本人明确选择不限时；这与整个resources为null的未配置状态不同。

单回调20秒是SDK通信协议限制，独立于整次运行预算；选择不限时也不会取消回调限制。自动测试只在临时目录使用明确标记的测试预算，不创建或替代本人的首次配置。
