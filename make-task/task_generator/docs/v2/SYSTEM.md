# 系统结构与信息边界

v2 将任务生产、Tushare 数据桥接和 AKQuant Docker 回测连接起来。市场数据保存在平台侧，公开题目包只包含接口需求与代码提交规范。

## 三个工具包的关系

|工具|输入|输出|主要使用者|
|---|---|---|---|
|Task 生产|来源卡、六类方向、历史库、模型配置|候选规格、去重证据、自动接纳的不可变版本与公开包|任务生产者|
|Tushare 桥接|可配置上游、字段规则、采集分区、时点证据|私有冻结版本、受限虚拟时间查询|数据运营者、策略|
|AKQuant 运行|冻结版本、交易规则、提交代码|系统生成的回测结果、可信检查点、提交记录|平台运行者|

固定流程为：历史登记或版本复用 → 模型生成 → 程序检查与模型复核 → 自动接纳入库 → 数据与规则绑定 → 研发回测 → 七段正式运行与维护 → 归档。题目规格不再要求人工审批；规格、审查证据或查重上下文不匹配时，自动接纳仍会失败。

题目新颖性与可运行规格分开记录。重复、变体不会计为独立新题，但通过运行规格检查和有效模型复核的候选可以登记为可复用执行版本。仅有旧历史ID时记录研究关系，不为旧题补造批准事实。旧人工批准记录及原分发快照保持原样；新自动记录注明机器接纳来源。

## 目录用途

```text
task_generator/
  taskgen/          模型适配、去重、模型复核、自动接纳、登记与导出
  finlab/           v2时间规则、Tushare桥接、SDK、Docker控制器与文档工具
  catalog/          来源、历史任务、六类方向、官方Pro接口快照与时间覆盖规则
  schemas/          原生v2任务规格与审核格式
  config/           模型配置、配额、运营方采集/冻结模板
  prompts/          任务生成、初筛及数据准备要求
  examples/v2/      六类规格草案和完整public示例
  registry/         SQLite身份、版本、变体、审核记录
  runs/             候选、初筛和检查记录
  exports/          接纳版本导出的公开包、内部评审包
  deployment/       Dockerfile、依赖锁和本机镜像锁
  docs/v2/          AI可阅读的系统协议
  .finlab/          本人交互确认的本机资源配置；不随工具包分发
  docs/index.html   可离线打开的完整中文说明
  work_v2/          运营方私有数据、冻结版本、episode与job；不打入源码包
  dist/             工具包压缩文件与版本清单
```

## 三种状态分别记录

规格接纳表示当前内容通过程序检查、有效模型复核，并保存不可变规格、公开内容和证据。数据绑定表示所需字段、覆盖范围、历史可见性与规则已确认并冻结。运行接入表示当前绑定和提交在固定镜像内完成了实际验证。三者分别记录；自动接纳不等于数据可用、Docker就绪或研发已通过，合成样本通过也不能替代真实任务数据验收。

## 信息分区

策略容器接收已完成行情切片、虚拟事件时钟、账户快照和 JSON memory。数据查询服务只开放当前任务允许的接口与字段，同时限制阶段累计披露范围和当前事件时钟。显式请求部分越界也整次拒绝并写私有审计；审计失败不返回行情。细则见[DISCLOSURE.md](DISCLOSURE.md)。

可信引擎容器读取私有冻结数据和平台检查点，使用真实日期处理交易日历与撮合，再将公开事件和结果转换为虚拟时间。原始数据、真实时间、上游令牌和检查点不挂载到策略容器。

每次运行使用新的内部 Docker 网络和两个新容器。只读文件系统、非root用户、资源限制和无外网出口共同限制提交代码。Python AST 检查只检查依赖与语法，不当作隔离保证。

真实名称与代码保留，名称或期货合约代码中的年月也保留。行情形态和标识仍可能帮助推断真实时期，因此该方案是时间字段隔离，不保证无法推断历史身份。

公开日期映射到未来数百年，是虚拟事件标签；不能根据虚拟年份套用现实股灾、政策或节假日。任务生成直接使用v2结构，历史题仅供去重对照，不转换或接受v1任务。

题目审批已取消；资源选择仍按既有约定，由使用者本人首次执行 `finlab setup`。2 CPU与4 GB仅为推荐，时限没有默认值；AI不能代选、代填或生成确认记录。运行前缺少本人配置会返回SETUP_REQUIRED。
