# 七段控制器与恢复协议

## 不可变输入与可变状态

binding.private.json冻结运行规则、真实窗口、已批准规格、数据哈希及段划分；state.private.json记录已提交段号、检查点位置、哈希和提交收据。disclosure.private.json由已冻结windows生成累计阶段范围，与episode绑定并核验哈希。控制器读取时重新计算绑定、披露策略与冻结版本哈希；范围缺失或无效不能打开服务。详细协议见[DISCLOSURE.md](DISCLOSURE.md)。

创建episode时同时记录可用的镜像ID；之后为其他任务重建镜像不会改变本任务。旧episode若没有镜像字段，从第一次成功提交收据取得固定ID。固定镜像缺失时停止运行，不能悄悄改用当前标签。

创建任务时默认按交易日将前30%划为研发期，其余平均划为七段；研发至少2日，正式每段至少2日。这里是程序默认规则，具体真实交易日取自冻结行情，公开只显示虚拟窗口。数据尚未绑定的候选包不预填日期。

真实任务必须对应当前已批准的v2规格哈希，冻结接口与字段须与已批准契约一致，并显式确认contract_review_confirmed。已升级但未批准的题、旧版本批准、接口扩大或未核验交易规则不能启动。合成测试使用独立synthetic标记，不写入真实规格批准状态。

## 一次运行的顺序

1. 取得episode文件锁，阻止并发推进；复制并哈希核验提交代码。
2. 校验固定镜像ID，读取上一次已提交的可信检查点、memory与账户文件。
3. 创建新的内部Docker网络、策略容器和可信AKQuant容器；上游Tushare凭证不进入任一策略请求。
4. 策略启动JSON RPC服务；可信引擎发送初始化、行情、订单和成交通知。
5. 引擎在真实交易时钟下撮合，桥接使用控制器传入的阶段范围和当前事件时钟；越界整次拒绝并写私有审计，允许的事件及公开结果映射为虚拟时间。
6. 成功完成全部回调、结果和检查点后，写success清单；宿主控制器逐项检查文件哈希。
7. 原子替换state.private.json作为唯一提交点，再开放本段研发数据；最后清理临时容器及网络。

若进程在第7步前退出，即使存在完整CSV，也不视为正式提交。重试依赖上一个已提交检查点，不读失败job产生的状态。用户提供的pickle从不加载。

## 研发与正式运行的区别

研发总是从初始资金重跑当前解锁范围，不继承正式持仓，也不改变正式状态。正式第1段从初始资金开始；后续段继承现金、持仓、未完成订单和JSON memory。段间可以换代码和参数，运行规则、数据版本和评分口径保持冻结。

正式成功提交后，研发服务即时读取最新段号；客户端无推进时钟、解锁后段或修改数据版本的接口。策略查询上限来自当前事件时钟，不能使用研发端已解锁边界代替策略时钟。

桥接每次查询固定范围与时钟快照，省略日期也不查询整库。越界请求不改变段号，日志失败也不放行行情。job的私有审计位于artifacts/bridge_audit.private.sqlite，研发服务的审计位于episode/bridge_audit.private.sqlite；容器销毁后仍保留在平台运行目录，不进入公开归档。

## 容器边界

|容器|可读取|不可读取|
|---|---|---|
|策略|五个提交文件、SDK、已完成切片、受限桥接、账户视图|原始冻结行情、真实时间映射、平台检查点、Docker socket、外网|
|可信引擎|平台维护的适配器、冻结行情、上一段可信状态|不导入或执行用户strategy.py|

每次两容器的总预算由使用者本人首次执行finlab setup确认，CPU与内存各分配一半。2CPU/4GB仅为推荐，不是默认选择；运行时限没有默认或推荐值，必须本人输入正整数秒或none（不限时）。AI不得代选、代填、生成确认记录或通过--timeout改写预算。未配置时禁止CLI启动回测；已创建episode保留冻结的本人选择，重新配置只影响新episode。单回调另有20秒协议上限，none不取消该限制。容器非root、只读根目录、移除capabilities，临时目录有容量限制。策略镜像只复制SDK与v2桥接客户端，不复制平台引擎、数据映射或控制器源文件。

网络使用Docker内部模式，并将外部DNS转发目标设为容器自身loopback，避免公共DNS成为外部出口；内部engine/worker别名仍由Docker网络解析。验收分别检查外部IP连接与外部域名解析。

## 版本锁定的特殊适配

AKQuant 0.3.76的warm-start入口不能直接重新登记自定义matcher。平台适配器在构造/恢复引擎时重新登记受控matcher和本段公司行为，随后恢复原函数符号。该实现绑定当前版本；升级AKQuant必须重新测试部分成交、跨段订单、公司行为和账户恢复，不能只改依赖号。

期货额外结算估值事件只用于按结算价估值，不触发策略、不允许成交。当前保证金账户保留AKQuant现金/浮盈结构，不实现交易所逐日现金划转；需要这一会计口径的正式实验应先扩展适配器并验收。
