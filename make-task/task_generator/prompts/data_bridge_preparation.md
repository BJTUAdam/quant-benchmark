# v2桥接数据准备

按照已批准任务的bridge_contract、schemas/data_api_profiles.v2.json及config/v2示例，使用可配置Tushare上游采集到运营方私有数据库。逐接口说明字段、单位、唯一键、分页、标的范围、覆盖缺口、可见时点证据和修订版本，不填造行情或检查成绩。

数据冻结时在平台侧应用年份映射；参与者只见虚拟日期、真实名称和代码。冻结缓存、真实时间范围、偏移量和上游凭证不进入public。虚拟年份不能用于关联现实历史事件，平台返回交易日历为准。

提交采集plan、冻结plan与运行binding；规格数据范围、交易规则缺口明确标记待绑定。resources保持null，由使用者本人执行finlab setup选择，AI不得代填或写确认文件；不输出默认运行时限。没有CSV行情包交付或v1任务转换步骤。
