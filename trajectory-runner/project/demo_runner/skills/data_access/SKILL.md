# 数据调用管理 Skill

该 Skill 将任务声明的数据查询收敛到 `data_query_market`。它仅转发至核心 `query_data`，不持有数据令牌、私有绑定、工作区路径或后端对象。

## 工作方式

1. 先读取 `TASK.md` 和 `DATA_API.md`，确认接口、字段、时间范围与分页规则。
2. 调用 `data_query_market`，仅查询当前可见范围。
3. 使用返回的保存路径作为后续研究或回测输入，并在 `RESEARCH.md` 记录覆盖范围与缺失情况。

## 检查清单

- 接口已被题目合约允许，字段与参数符合接口约定。
- 查询范围没有跨越当前研发可见边界。
- 缺失、空结果和异常值已报告，未静默补零。
- 分页或分批查询的合并规则可由已保存 JSON 复核。

可运行 `python scripts/checklist.py --input 请求.json` 对请求元数据做离线清单检查；该脚本不调用数据服务。
