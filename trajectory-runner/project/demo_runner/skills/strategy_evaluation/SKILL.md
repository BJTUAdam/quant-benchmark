# 策略评估 Skill

该 Skill 提供 `strategy_evaluate`，仅转发到核心 `run_research`。它用于分析已有研究结果，不能绕过禁网沙箱执行策略回测或访问平台评分。

## 工作方式

1. 从已保存的本地回测结果提取收益、夏普、最大回撤和交易成本。
2. 按区间、仓位或市场状态归因，检查结果是否只由单段或少数交易驱动。
3. 在样本量足够、输入定义明确时再计算 DSR、PBO 等统计量；否则明确标记为未计算。
4. 将改善判断、反例和残余风险写入 `RESEARCH.md`。

## 检查清单

- 多个区间的方向一致才可视为改善。
- 未因单一收益或夏普指标掩盖回撤与成本风险。
- 统计量的输入、假设和不适用原因可复核。
- 结论包含失败区间、容量或换手压力等限制。

可运行 `python scripts/checklist.py --input 评估元数据.json` 检查报告所需元数据；该脚本不生成虚假的统计结论。
