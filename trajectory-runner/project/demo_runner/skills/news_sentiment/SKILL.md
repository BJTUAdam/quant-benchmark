# 新闻情绪评估 Skill

该 Skill 通过 `news_query_text` 读取题目合约允许的新闻、公告或研报文本，再通过 `news_score_sentiment` 在禁网 Docker 中生成可审查的情绪结果。两者分别只转发至核心 `query_data` 和 `run_research`。

## 工作方式

1. 确认可用接口、发布时间字段和当前研发可见边界。
2. 查询文本并保留记录标识、发布时间、主体和来源字段。
3. 用明确的打分规则汇总为品种或个股的情绪时间序列。
4. 情绪成为交易信号前，以不重叠的样本外区间进行本地回测验证。

## 检查清单

- 只使用发布时间不晚于当前可见边界的文本。
- 每个情绪分可追溯到原始记录标识、规则和聚合窗口。
- 无文本或字段不足时已报告限制，未联网补齐数据。
- 作为信号前已与训练窗口分离进行样本外检验。

可运行 `python scripts/checklist.py --input 情绪元数据.json` 检查时间边界和可复核字段；该脚本不访问网络或数据接口。
