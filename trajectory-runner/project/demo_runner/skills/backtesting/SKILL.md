# 回测 Skill

该 Skill 提供 `backtest_run_local`，并且只转发到禁网 Docker 内的核心 `run_local_backtest`。它不是平台评测器，也不读取未公开数据。

## 工作方式

1. 基于保存的查询数据建立基线和待比较方案。
2. 明确手续费、滑点、仓位、调仓频率和起止边界。
3. 用完整代码进行基线、参数或分段独立账户对照，并将结果写入 `RESEARCH.md`。

## 检查清单

- 手续费和滑点已进入所有比较组。
- 参数扫描在本轮研究额度内完成，且扫描范围已记录。
- 分段比较使用独立账户，不混入正式连续账户净值。
- 代码、数据输入、参数和关键输出足以复现结论。

可运行 `python scripts/checklist.py --input 回测元数据.json` 检查研究元数据；该脚本不会运行回测。
